# Andrew-R's darwinbuild patch

Andrew-R published `loacalhack_9.diff` (name as published, SHA-256 `b3324501bae6272f285699471f936955248ccdcbd48a7d260af7c055bad4bdf7`) in [`localhack_darwin9.zip`](https://forums.macrumors.com/attachments/localhack_darwin9-zip.2646677/) (SHA-256 `ac9ce718c1bbc6b9a156695cce882aa12eb4b3715135e670f1668a9fe36eb11c`), attached on 2026-07-20 to [his post](https://forums.macrumors.com/threads/building-with-darwinbuild-for-darwin9-ppc-in-2026-wip.2485638/post-34688418) in the MacRumors thread [Building with darwinbuild for Darwin9/ppc in 2026 [WIP]](https://forums.macrumors.com/threads/building-with-darwinbuild-for-darwin9-ppc-in-2026-wip.2485638/). It applies to the `Darwin9` branch of [macosforge/darwinbuild](https://github.com/macosforge/darwinbuild). It is not copied here, since it carries no licence.

It changes three things: the default build-list site, from the dead `svn.macosforge.org` to `macos-powerpc.org/darwinbuild/plists`; the symlink darwinbuild makes for alias projects; and the Roots and source sites in each 9* build list, from the dead `src.macosforge.org` to `macos-powerpc.org/darwinbuild/`. On 2026-11-18 that host's `Roots/` folder was empty, so this repo fetches the Roots from archive.org with `scripts/fetch-roots` instead.
