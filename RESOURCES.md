# Resources

Earlier work, tools and sources for building Darwin on PowerPC, as found on 2026-11-18, with additions of 2026-11-22.

## People working on it now

- [Building with darwinbuild for Darwin9/ppc in 2026 [WIP]](https://forums.macrumors.com/threads/building-with-darwinbuild-for-darwin9-ppc-in-2026-wip.2485638/) (MacRumors, Andrew-R, 20–22 July 2026): darwinbuild's `Darwin9` branch on a Leopard PowerPC Mac, 100 Darwin 9 projects built including `xnu-1228.15.4`, never assembled into a bootable system. His patch is described in [reference/andrew-r/](reference/andrew-r/README.md).
- [Reviving Darwin Build?](https://forums.macrumors.com/threads/reviving-darwin-build.2490592/) (MacRumors, from 27 September 2026): alex_free wants a full mirror of Apple's open-source releases; Andrew-R tried darwinbuild on the fifth 10.6.8 alpha for PowerPC and gave up, its Xcode leaning too far towards Intel; barracuda156 finds darwinbuild "too messy and painful" for single components.
- [barracuda156](https://github.com/barracuda156) (Sergey Fedorov) and the [macos-powerpc](https://github.com/macos-powerpc) organisation: [macos-powerpc/darwinbuild](https://github.com/macos-powerpc/darwinbuild), whose `Darwin10` branch adds ppc to `10A432` and replaces dead URLs (December 2024); build lists at `macos-powerpc.org/darwinbuild/plists/` (its `Roots/` folder was empty on 2026-11-18); barracuda156's own forks of PureDarwin's Libsystem and XPC; [apple-libdispatch-powerpc](https://github.com/barracuda156/apple-libdispatch-powerpc); [powerpc-ports](https://github.com/macos-powerpc/powerpc-ports).
- [doctashay/xnu](https://github.com/doctashay/xnu), branch `g5-platform` (srp on MacRumors, [5 June 2026](https://forums.macrumors.com/threads/sorbet-leopard-your-power-mac-unleashed.2300924/post-34615771)): Darwin 9.8's xnu built from source and booted on a Power Mac G5 under Leopard's userland, with the G5 platform code that Apple did not publish rebuilt from the platform kexts of the PCI-X G5s; a kernel only.
- [Christopher-Charman/apple.powerpc.darwin10](https://github.com/Christopher-Charman/apple.powerpc.darwin10) (from September 2026): a source tree for Darwin 10 on PowerPC, by its README a development baseline and not a completed port.
- [alex-free](https://github.com/alex-free): tigerports, SDL2 for Panther and Leopard.
- [10.6 Snow Leopard PowerPC – Development](https://forums.macrumors.com/threads/10-6-snow-leopard-powerpc-development.2439769/) (MacRumors): the group that built `10A432`'s kernel, `xnu-1456.1.26`, for PowerPC from source in May 2024; their 10.6.8 images run Apple's own 10.6.8 kernel, binary-patched. `xnu-1504.9.37`, sometimes attached to this work, is 10.6.7's kernel. Summary in [LowEndMac](https://lowendmac.com/2024/mac-os-x-snow-leopard-10-6-10-6-8-for-powerpc/), which says that 10.6.8's kernel was compiled from source, where the group's developer says it is Apple's, patched.

## Earlier attempts

- Apple's last bootable Darwin, 8.0.1 for PowerPC, still served by Apple at `https://opensource.apple.com/static/iso/darwinppc-801.cdr.gz` (428 MB), with its [release notes](https://opensource.apple.com/static/iso/release-notes-8.0.1.txt).
- Craig Harman's [HOWTO](http://web.archive.org/web/20161003130558/http://lists.apple.com/archives/darwin-dev/2006/Nov/msg00000.html) (2 November 2006) for building Darwin 8.7 (Mac OS X 10.4.7) for PowerPC with darwinbuild on a G5, which builds packages, not a bootable system, and Graham Lee's [G4 file system built from Darwin 8's open-source components](http://web.archive.org/web/20140115100001/http://lists.apple.com/archives/darwin-dev/2006/Mar/msg00065.html) (7 March 2006), whose kernel panicked at once; both on Apple's darwin-dev list.
- [Darwin 9](https://forums.macrumors.com/threads/darwin-9.2400556/) (MacRumors, oldskooltech, September 2023): Darwin 9.8 built without darwinbuild, all but `relpath`, with xnu still to compile; no boot reported.
- [PureDarwin](https://github.com/PureDarwin/PureDarwin): Darwin 9 "Nano" and rafirafi's 2012 Darwin 9.8 build, Intel only; [PureDarwin/darwinbuild](https://github.com/PureDarwin/darwinbuild).
- PureDarwin's X11 pages, in a copy of its wiki at [heldersrvio/PureDarwin](https://github.com/heldersrvio/PureDarwin/wiki): [XFree86](https://github.com/heldersrvio/PureDarwin/wiki/XFree86), XFree86 4.7.0 in its IOKit mode on Darwin 9 for Intel in VMware, built through MacPorts' `+puredarwin` variant with `DarwinQuartzSupport NO` and FreeType without its Mac font support ([MacPorts ticket 16697](https://trac.macports.org/ticket/16697)), running twm, WindowMaker, fluxbox and Qt 3 programs; [TightVNC](https://github.com/heldersrvio/PureDarwin/wiki/TightVNC) and Xfce from MacPorts; [X.Org for PureDarwin](https://github.com/heldersrvio/PureDarwin/wiki/X.Org_for_PureDarwin), Guillaume Verdeau's patches to run X.Org on PureDarwin, after X.Org had removed the IOKit mode.
- [steventroughtonsmith/BootX](https://github.com/steventroughtonsmith/BootX): BootX-34 patched to boot Mac OS X Server 1.0 in `qemu-system-ppc`, with the QEMU options it needs.
- [neozeed/Darwin_0.1](https://github.com/neozeed/Darwin_0.1) and [Rebuilding Darwin from source](https://virtuallyfun.com/2024/04/22/rebuilding-darwin-from-source-part-1-qemu/) (virtuallyfun, 2024): Darwin 0.1 rebuilt on x86 in QEMU.

## Tools

- [macosforge/darwinbuild](https://github.com/macosforge/darwinbuild), archived; this project uses its `Darwin9` branch at `4848b7f` unchanged.
- [wam-slop/llvm-powerpc-apple-darwin](https://github.com/wam-slop/llvm-powerpc-apple-darwin) (from 12 November 2026): LLVM with `powerpc-apple-darwin8/9` restored, ARC and blocks on Tiger and Leopard. Not Apple's toolchain, so not for this project's builds; useful for later Cocoa work.
- [darwin-xtools](https://github.com/barracuda156/darwin-xtools): updated cctools and ld64 that still target ppc.
- [VariantXYZ/gcc-powerpc-apple-darwin8](https://github.com/VariantXYZ/gcc-powerpc-apple-darwin8): Docker cross toolchain for Tiger on PowerPC.
- [Scottcjn/darwin-ppc-gpu](https://github.com/Scottcjn/darwin-ppc-gpu) (2026): IOKit drivers for modern AMD GPUs on PowerPC Tiger and Leopard, mostly design documents so far.
- NetBSD's macppc [`smu.c`](https://github.com/NetBSD/src/blob/trunk/sys/arch/macppc/dev/smu.c) and [`pmu.c`](https://github.com/NetBSD/src/blob/trunk/sys/arch/macppc/dev/pmu.c) (BSD licence): the clock, power-off and restart commands of the SMU and the PMU, and how a byte crosses the PMU's VIA, which OpenSMU and OpenPMU follow in place of Apple's closed AppleSMU and ApplePMU, and in `smu.c` the SMU's fan, sensor and SDB partition commands. OpenSMU ([D81](DEVIATIONS.md#d81)) speaks the same SMU protocol, and its fan zones work as those of `smu.c` and [`fancontrol.c`](https://github.com/NetBSD/src/blob/trunk/sys/arch/macppc/dev/fancontrol.c) (Michael Lorenz, BSD licence) do, without their code. Linux's `drivers/macintosh/smu.c` and `via-pmu.c` describe the same, under GPL-2.0-only.
- Apple's [AppleMacRISC4PE 186.3.1](https://github.com/apple-oss-distributions/AppleMacRISC4PE/tree/AppleMacRISC4PE-186.3.1) (APSL, Tiger), the last release that holds the platform plug-ins: `IOPlatformPlugins/PowerMac12_1PlatformPlugin/` and `SMU_Neo2_PlatformPlugin/` are the source of the iMac G5's fan control, and the `PowerMac12_1_ThermalProfile` 1.8.6f1 personality, in the Info.plist inside `AppleMacRISC4PE.pbproj/project.pbxproj`, holds its sensors, fans, target temperatures and the 500 rpm rubber band, the same as Leopard's closed 3.4.0d0 profile. OpenSMU's fan zones and rubber band take their values from it ([D81](DEVIATIONS.md#d81)). Linux's [`windfarm_pm121.c`](https://github.com/torvalds/linux/blob/master/drivers/macintosh/windfarm_pm121.c) (GPL-2.0-only) re-implements it from the Darwin 8.10 property lists; read for its facts only.
- FreeBSD's [`fwohci.c`](https://github.com/freebsd/freebsd-src/blob/main/sys/dev/firewire/fwohci.c) (BSD licence): a driver for OHCI-1394 FireWire controllers, a source of facts for OpenFWOHCI ([D119](DEVIATIONS.md#d119)), our stand-in for Apple's closed `AppleFWOHCI`.
- The 1394 Open Host Controller Interface specification, release 1.1: the registers, DMA contexts and descriptors that OpenFWOHCI programs.
- Linux's [`drivers/firewire/ohci.c`](https://github.com/torvalds/linux/blob/master/drivers/firewire/ohci.c) (GPL), read for facts only: how real OHCI-1394 controllers behave.
- FreeBSD's [`onyx.c`](https://github.com/freebsd/freebsd-src/blob/main/sys/dev/sound/macio/onyx.c) (BSD licence): the PCM3052 (Onyx) codec's registers and the values it sets them to, for OpenOnyx ([D94](DEVIATIONS.md#d94)), our stand-in for Apple's AppleOnyxAudio, published only as a stub.
- X.Org's [xf86-video-ati 6.14.6](https://gitlab.freedesktop.org/xorg/driver/xf86-video-ati/-/tree/xf86-video-ati-6.14.6) (MIT licence): `src/radeon_pm.c`'s `LegacySetClockGating`, whose branch for the RV350 family OpenRadeonPM follows ([D117](DEVIATIONS.md#d117)), our idle power settings for the iMac G5's RV370, and `src/radeon_reg.h`, the registers' offsets and bits.
- Linux's [`radeonfb`](https://github.com/torvalds/linux/tree/master/drivers/video/fbdev/aty) (GPL), `radeon_pm.c` and `radeon_base.c`, read for facts only: when it switches an ATI GPU's dynamic clocks on.
- Howard Hinnant's [date algorithms](https://howardhinnant.github.io/date_algorithms.html) (public domain): the day counts with which OpenSMU converts the SMU's dates.
- QEMU's model of the PMU, [`hw/misc/macio/pmu.c`](https://github.com/qemu/qemu/blob/master/hw/misc/macio/pmu.c) (GPL), read for facts only: how it answers each command and the handshake on the VIA's port B, against which OpenPMU was tested ([D118](DEVIATIONS.md#d118)).
- X.Org's [xorg-server 1.4.2](https://gitlab.freedesktop.org/xorg/xserver/-/tree/xorg-server-1.4.2/hw/darwin) (MIT), the release that Apple's 1.4.2-apple33 starts from: its `hw/darwin` builds XDarwin, whose IOKit mode runs on IOKit's framebuffer and IOHIDSystem's input with no WindowServer. X.Org deleted `hw/darwin/iokit` with commit [`bcbaf2a0`](https://gitlab.freedesktop.org/xorg/xserver/-/commit/bcbaf2a0ce34b6c5e41d2831b8b87dbd0617a89b) of 21 November 2007, so 1.5 and later have none ([A graphical interface](docs/src/steps/graphical-interface.md)).
- GNUstep's [README.Darwin](https://github.com/gnustep/tools-make/blob/master/Documentation/README.Darwin), last updated in December 2007: GNUstep on Darwin for PowerPC with Apple's compiler and the GNU Objective-C runtime, with libffi, libtiff and an X server. GNUstep's [libs-base](https://github.com/gnustep/libs-base), [libs-gui](https://github.com/gnustep/libs-gui) and [libs-back](https://github.com/gnustep/libs-back) are under the LGPL-2.1.
- VNC servers for an X server's screen: [LibVNC/x11vnc](https://github.com/LibVNC/x11vnc) on [LibVNC/libvncserver](https://github.com/LibVNC/libvncserver), and [TigerVNC](https://github.com/TigerVNC/tigervnc), whose Xvnc is an X server; all GPL-2.0. [WindowMaker](https://github.com/window-maker/wmaker) (GPL-2.0), a window manager in NeXTSTEP's style, and [LVGL](https://github.com/lvgl/lvgl) (MIT), a graphical toolkit that draws into a framebuffer without X.

## Apple's sources and binaries

- [apple-oss-distributions](https://github.com/apple-oss-distributions) (since 4 October 2021): one repo per project, one tag per version; 372 of the 386 versioned 9L30 projects have their exact tag. Index: [opensource.apple.com/releases](https://opensource.apple.com/releases/) ("Mac OS X 10.5.8", 369 projects).
- The old `opensource.apple.com/release/mac-os-x-1058/` pages and tarballs, now only on the Wayback Machine.
- darwinbuild's Roots, `src.macosforge.org/Roots/<build>/`, on the Wayback Machine, from ArchiveBot's crawl of 23 February 2014, whose WARC on archive.org is access-restricted. The Wayback Machine refuses connections after a burst of requests, sometimes for several minutes; `scripts/wayback-fetch` tries a refused download again for an hour. [nyg/PowerDarwin-roots](https://github.com/nyg/PowerDarwin-roots) keeps a copy of the 524 Roots used that are under an open-source licence, each with its source, and `scripts/fetch-roots` downloads from it first. PureDarwin's [puredarwin.roots](https://github.com/PureDarwin/puredarwin.roots) and macos-powerpc.org's `darwinbuild/Packages/` hold their own builds, not Apple's. [darwinbuild-dev, July 2010](http://web.archive.org/web/20240915005301/http://lists.macosforge.org/pipermail/darwinbuild-dev/2010-July/000641.html) confirms where they were served from. Apple served them again at `opensource.apple.com/darwinbuild/Roots/` ([captured on 8 April 2018](https://web.archive.org/web/20180408161609/https://opensource.apple.com/darwinbuild/Roots/)), an address that now answers 404.
- Later Apple releases that fixes are backported from: CF-550 and DirectoryService-621 (Mac OS X 10.6), CF-635 (Mac OS X 10.7), Security-55471 (OS X 10.9), whose `libsecurity_codesigning/antlr2` holds ANTLR 2.7.7, and [swiftlang/swift-corelibs-foundation](https://github.com/swiftlang/swift-corelibs-foundation), Apple's later open CoreFoundation, under Apache 2.0 with Runtime Library Exception.
- Apple's X11 for Leopard, six projects of the 9L30 build list: [X11proto](https://github.com/apple-oss-distributions/X11proto/tree/X11proto-15.5) 15.5 (with FreeType 2.3.9 and fontconfig 2.6.0), [X11libs](https://github.com/apple-oss-distributions/X11libs/tree/X11libs-17.6) 17.6, [X11apps](https://github.com/apple-oss-distributions/X11apps/tree/X11apps-14.3) 14.3, [X11fonts](https://github.com/apple-oss-distributions/X11fonts/tree/X11fonts-5.1) 5.1, [X11misc](https://github.com/apple-oss-distributions/X11misc/tree/X11misc-6) 6 and [X11server](https://github.com/apple-oss-distributions/X11server/tree/X11server-48.7) 48.7, whose `build` makes Xquartz and, in a second configuration, Xvfb, Xnest, Xephyr and Xfake. Apple's earlier [X11](https://github.com/apple-oss-distributions/X11) project holds XDarwin's IOKit mode in `xc/programs/Xserver/hw/darwin`: X11-0.30.4 for Mac OS X 10.3.4 to 10.3.9, X11-0.40, X11-0.40.2 and X11-0.40.80 for 10.4 to 10.4.8, by [Apple's release list](https://opensource.apple.com/releases/); X11-0.40.2 is XFree86 4.4.0, and X11-0.46.4, for 10.4.9 to 10.4.11, has no IOKit mode.
- DarwinTools 1, Darwin 8's project with Apple's open `sw_vers` ([D121](DEVIATIONS.md#d121)), filed by Apple among the projects of `opensource.apple.com/darwinsource/projects/other/` and named by darwinbuild's Darwin 8.0 build list, `8A428`. Neither site serves them any more, and the Wayback Machine keeps both: the tarball, [captured on 8 April 2018](https://web.archive.org/web/20180408044816/https://opensource.apple.com/tarballs/DarwinTools/DarwinTools-1.tar.gz), which [nyg/PowerDarwin-roots](https://github.com/nyg/PowerDarwin-roots) also keeps, and the build list, OpenDarwin's `darwinsource.opendarwin.org/plists/8A428.plist`, [captured on 18 May 2006](https://web.archive.org/web/20060518081653/http://darwinsource.opendarwin.org/plists/8A428.plist).
- Xcode 3.1.4 (`xcode314_2809_developerdvd.dmg`), from developer.apple.com/download/all with a free Apple account.
